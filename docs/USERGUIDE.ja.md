# 操作マニュアル — 勤怠・交通費システム

朝日新聞総合サービス株式会社　アルバイト勤怠・交通費管理システム
（English version: [USERGUIDE.en.md](./USERGUIDE.en.md)）

はじめてご利用になる方向けの操作手引きです。画面の例は 2026年6月のサンプルデータです。

---

## 1. このシステムでできること

高校野球のアルバイト勤務について、次を行います。

- 日々の**勤怠**（勤務日・時間・球場）と**交通費・経費**の記録
- 記録から**勤務表・請求明細書・給料計算書ほか**を自動作成（PDF・メール送信）
- 所得税（日額表・丙）・交通費・弁当代などを自動計算

利用者は 2 種類です。

| 役割 | できること |
|---|---|
| **アルバイト**（スタッフ） | 自分の勤怠・経費の入力、自分の月次書類の表示・PDF・メール送信 |
| **管理者** | 全アルバイトの実績確認、各種マスタ（球場・アルバイト・区間運賃・単価・アカウント）の管理、メール設定 |

## 2. ログイン

1. システムの URL を開きます。
2. **メールアドレス**と**パスワード**を入力し、「**ログイン**」を押します。
3. パスワード欄右の**目のアイコン**を押すと、入力内容を表示／非表示できます。
4. 画面右上の **EN / 日本語** ボタンで表示言語を切り替えられます。

デモ用アカウント（ログイン画面にも表示されます）:

| 役割 | メールアドレス | パスワード |
|---|---|---|
| 管理者 | admin@example.com | admin123 |
| アルバイト | staff@example.com | staff123 |

ログインすると、役割に応じた最初の画面（アルバイト＝マイページ、管理者＝全体実績）が開きます。

## 3. アルバイト（スタッフ）の操作

上部メニュー：**マイページ / 勤怠・交通費入力 / 月次実績・書類**

### 3-1. マイページ

当月の集計（稼働日数・合計勤務時間・交通費・差引支給額・給料・支給額計・所得税）と、日別の明細が表示されます。右上の**対象月**で月を切り替えられます（データのある月で開きます）。

### 3-2. 勤怠・交通費入力

**勤務日の追加**（上部の入力欄）:

1. **勤務日**・**球場**・**始業**・**終業**を入力します。
2. **休憩**：チェックボックス「**休憩あり**」を入れ、右の**2つの欄に「時間」と「分」を分けて**入力します。

   | 休憩 | 入力 |
   | --- | --- |
   | 1時間 | `1` 時間 `0` 分 |
   | 30分 | `0` 時間 `30` 分 |
   | **1時間25分** | **`1` 時間 `25` 分** |

   - **紙の勤務表の「1:25」を、そのまま2つの欄に写せます。**分単位で自由に入力できます。
   - 「分」欄は 0〜59 です。1時間以上は左の「時間」欄に入れてください。
   - **小数（`1.25` など）は入力できません。**時間・分が分かれているため、`1.25` を「1時間25分」と取り違える余地がありません。
   - チェックを外すと、休憩なし（0分）として登録されます。
   - 入力（時間・分）と、画面や勤務表（PDF）の表示（`1:25`）は同じ意味です。換算は不要です。
3. **弁当代有無**：`○（有）`／`×（無）`を選びます。
   - **1日の実働が6時間を超える日のみ選択可**です。6時間以下の日は選べず、「選べません（実働6時間以下は対象外）」と表示されます。
4. 「**勤務日を追加**」を押します。
   - 自宅最寄り駅⇔球場最寄り駅の**区間運賃が登録されていれば、交通費（往復）が自動計上**されます。未登録の場合は勤務日のみ登録され、交通費は後から管理者が区間を登録すれば反映されます。

**登録済みの勤務日**（一覧表）:

- 日付・球場・始業・終業・実働・**時間外**・**弁当代有無（○/×）**が並びます。
- **時間外**列は、実働が8時間を超えた分を自動表示します（8時間以内は「—」）。
- 各行の **鉛筆アイコン**＝その日の内容を修正、**ゴミ箱アイコン**＝削除。

**交通費・経費明細**:

- 自動計上された交通費のほか、私有携帯電話使用料・出張日当・宿泊実費・その他などの経費を確認できます。

### 3-3. 月次実績・書類

5 種類の書類を作成できます。

| 書類 | 内容 |
|---|---|
| 勤務表 | 日別の勤務（始業・終業・休憩・実働・弁当代有無 ○/×） |
| 交通費（別紙） | 片道ごとの区間・運賃明細 |
| 出張日当・私有携帯・その他（別紙） | 各手当・経費の明細 |
| 請求明細書 | 給料・交通費・その他の請求内訳 |
| 給料計算書 | 支給額・所得税・差引支給額 |

**時間の表示形式（現行様式と同じです）**

勤務表および画面上の **休憩・実働・時間外・夜勤**、ならびに各合計は、すべて **時:分** で表示されます。小数ではありません。

| 欄 | 表示例 |
|---|---|
| 休憩時間 | `1:00` / `1:25` |
| 実働時間（除休憩） | `7:50` / `7:35` |
| 直接費・間接費 合計、総合計（実働） | `101:00` / `108:35` |
| **時給換算用勤務時間（この欄のみ小数）** | `101` / `108.58` |

- 15分単位に限らず、`1:25` のような分単位の休憩もそのまま表示されます。
- 合計は24時間を超えても `101:00` のように積み上げ表示されます（`5:00` のように折り返しません）。
- 小数になるのは **「時給換算用勤務時間」欄だけ**です。同欄は「時給 × この数値」で給料を算出するための数値です（2026年6月の例：`101` × 1,300円 ＝ 131,300円）。

> **【要ご確認】時給換算用勤務時間の端数表記**
> 頂戴した2026年6月の勤務表は合計がちょうど `101:00`（＝ `101`）のため、**端数が出る月にどう表記されているかが現行様式からは判断できません**。
> 本システムは小数第2位まで（例：合計 `108:35` → `108.58`）で出力しています。貴社の運用と異なる場合はお知らせください。表記は変更できます。

各書類のカードで:

- **表示**：内容を画面下部に表示
- **PDF**：PDF を新しいタブで開く（保存可）
- **メール送信**：登録メールアドレス（または管理者が設定した確認用アドレス）へ PDF 付きで送信
- 表示中の書類は「**印刷 / PDF保存**」からも保存できます。

**PDF について（デモ環境で動作します）**

- デモ環境（Render）でも **サーバー側で PDF を生成**します。日本語フォント（Noto Sans JP）を同梱しているため、漢字・かなも文字化けしません。1書類あたり **おおむね5秒以内**で生成されます。
- 画面下部に「**PDF: サーバー生成 有効**」と表示されていれば、PDFボタンが使えます。
- 万一サーバー側で生成できない環境の場合は、PDFボタンを押すと「**印刷 / PDF保存 をご利用ください**」と表示されます。その場合は「**表示**」→「**印刷 / PDF保存**」でブラウザから保存してください（内容は同一です）。

## 4. 管理者の操作

上部メニュー：**全体実績 / 球場マスタ / アルバイトマスタ / アカウント管理 / 区間別交通費 / 単価設定 / メール設定**

### 4-1. 全体実績

全アルバイトの月次集計（稼働日数・実働・**時間外**・給料・交通費・所得税・差引支給額・**弁当代**）を一覧表示します。

- **時間外**列は、その月の8時間超の合計時間と、その**割増分（円）**を表示します。

- **弁当代**列は、対象日（○）×**単価設定の弁当代**の合計です。弁当代が未設定（0円）の間は 0 円と表示されます。
- 各行の「**詳細**」で、その人の**日別明細**を開きます。日別では各日を **大会経費（直接費）／編集費（間接費）** に振り分け（区分の変更）できます。交通費も同じ区分に移動します。**弁当代有無（○/×）**も表示されます。

### 4-2. マスタ管理

| 画面 | 内容 |
|---|---|
| 球場マスタ | 球場名・住所・最寄り駅 |
| アルバイトマスタ | 氏名・郵便番号・住所・自宅最寄り駅・電話 |
| 区間別交通費 | 自宅最寄り駅 ⇔ 球場最寄り駅の**片道運賃**（自動計上の元になります） |
| 単価設定 | 時給・時間外（60h以下／超）・深夜割増・**弁当代（定額）** |
| アカウント管理 | アカウントの作成・権限変更・パスワード再設定・削除 |

**弁当代の金額**は「単価設定」で入力します。初期値は **0 円**です。金額を入れて保存すると、対象日（○）の給料に加算され、書類・全体実績に反映されます。

### 4-3. メール設定

書類メールが正しく届くかを確認するための画面です。

- **確認用の受信アドレス**を設定すると、すべての書類メールがそのアドレスに送られます（各アルバイトの登録アドレスは変更されません）。
- 「**テスト送信**」で試し送信できます。
- 欄を空にして保存すると、通常どおり各アルバイトのアドレスへ配信されます。

**デモ環境でメールをお試しいただく手順**

デモ環境でも**実際にメールが届きます**（HTTPS経由の配信。送信結果は確認済みです）。ただし、サンプルのアルバイトの登録アドレスは `staff@example.com` という**実在しないアドレス**のため、そのままでは届きません。次の順でお試しください。

1. **メール設定**を開き、**ご自身の受信アドレス**を入力して保存します。
2. すぐに（間をあけずに）**月次実績・書類**へ移動し、いずれかの書類の「**メール送信**」を押します。
3. 受信箱をご確認ください。**迷惑メールフォルダ**に入る場合があります。

- メールには、書類の内容が**本文（HTML）**として入り、さらに同じ書類が **PDF で添付**されます。
- 送信に成功すると、画面に送信先が表示されます。

> **【ご注意】デモ環境ではメール設定が初期化されます**
> デモ環境はデータをサーバー上に保持しないため、**一定時間アクセスがないと停止し、再開時にメール設定（確認用アドレス）も空に戻ります**。
> 空に戻った状態で「メール送信」を押すと、送信先が `staff@example.com` になり、**送信成功と表示されても実際には届きません**。
> お試しの直前に、必ず**メール設定にアドレスが入っているかご確認ください**。本番環境（データベースを常設）ではこの初期化は起こりません。

## 5. 計算のしくみ（参考）

- **給料**：各日の「実働時間 × 時給」を合計（＋時間外割増、＋課税対象の経費）。
- **時間外（残業）**：**1日の実働が8時間を超えた分**に自動で付きます。**入力は不要**です。
  - 例：実働9時間 → `1,300円 × 8時間 ＋ 1,300円 × 1.25 × 1時間 ＝ 12,025円`
  - 請求明細書では「時給（実働全体）」と「時間外（割増分）」に分けて記載されます。
  - 月の時間外が **60時間**を超えた分は、より高い割増単価（既定 1.5 倍相当）になります。
  - 休憩は実働に含みません。例：10:00〜19:00・休憩1時間 ＝ 実働8時間 → 時間外なし。
- **所得税**：**日額表・丙**で**1日ごと**に算出し合計します（月合計に対してではありません）。1日の課税対象額が約 9,800 円を超えた日から発生します。時間外の割増分も課税対象に含まれます。
- **「暫定」表示について**：本システムに収録している日額表・丙は **1日 14,800 円まで**です。それを超える日の税額は**収録範囲外の暫定計算（推計値）**となります。
  - 該当する日があると、**マイページ**・**全体実績**・**給料計算書**に「**暫定**」と表示され、対象日が明記されます。表示が無ければ、すべて収録範囲内の正式な税額です。
  - 時間外を支払うと、**実働 約10時間45分**（課税対象額 14,869円）から該当します。時間外が無い場合は約11時間24分からでした。
  - **暫定表示のある月は、所得税・差引支給額が確定額ではありません。**正式な税額をご確認のうえ確定してください。
- **交通費**：登録した**片道運賃 × 2（往復）× 勤務日数**。非課税です。
- **弁当代**：**大会期間中**かつ**1日の実働が6時間を超える**日に定額。金額は「単価設定」で設定します（未設定は 0 円）。

## 6. 補足・ご注意

- 各画面は**データのある月**で開きます。データを入れると当月で開きます。
- デモ環境はサーバー再起動時にデータが初期化され、サンプル（2026年6月）に戻ります。
- 所得税の日額表・丙は現在 1日 14,800 円までを収録しています。それを超える日は暫定計算となり、画面と給料計算書に「**暫定**」と表示されます（5章参照。正式値は要確認）。

ご不明点は担当（モラブ阪神工業）までお問い合わせください。
